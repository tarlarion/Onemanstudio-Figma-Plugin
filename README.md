# Figma Plugin

Minimal starter. Add your logic in `code.js` and UI in `ui.html`.

## Run in Figma

1. **Plugins** → **Development** → **Import plugin from manifest…**
2. Select this folder (the one containing `manifest.json`).

## Files

- `manifest.json` – plugin name, id, entry points
- `code.js` – runs in Figma (canvas, selection, API)
- `ui.html` – plugin panel (HTML/CSS/JS)
