Frame Name

Rename frames

Select frames. Each name is prefix plus a number (e.g. Frame-01, Frame-02). Prefix: letters only.

When off (default), order follows canvas position (top → bottom, left → right). When on, order follows the Layers panel bottom → top (reverse of the list).
